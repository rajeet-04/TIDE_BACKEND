Hooghly estuary · 1 Jul – 30 Sep 2026 · IST

Hooghly Tide Source Audit

High and low tide events for Haldia and Diamond Harbour from three sources: our UTide event model, the monthly reference-table PDFs, and the remote tide API. The PDFs cover July and August; September PDFs are not in the repo, so September is checked against the API only.

Which source is right

PDF and API are the same table

After correcting the API clock, all 478 July–August events match the PDF exactly: same time to the minute and same height to the centimetre. The API is a copy of the published tables. It adds September, which the repo has no PDF for.

The API clock is wrong

API timestamps are labelled UTC (Z) but sit 11 h before the IST value in the PDF. True UTC is IST − 5:30, so the API subtracts the IST offset twice. The reported time is 5 h 30 min earlier than true UTC on every event.

The model is the one that drifts

Against the published tables the model misses the joint 95% gate (±30 min and ±0.30 m) at both ports. It predicts events early and too high, with a consistent bias you can correct.

Model error, event by event

Each dot is one tide event: model minus reference (PDF for Jul–Aug, API for Sep). The shaded band is the accuracy gate. Negative time means the model predicts the event early.

Bias by month and tide state

Mean model-minus-reference error. The bias holds steady from month to month, which is what makes a fixed correction work. Low tides at both ports come in 11–18 minutes early.

Timing error across the lunar cycle

Mean timing error grouped by moon age. The largest early bias falls between first quarter and full moon, around neap tides, where the tidal curve is flattest and turning points are hardest to place.

Model tuning parameters

Per-state corrections, fitted on July and scored on August so the check is out of sample. Apply them after the ExtraTrees calibration: time += time_offset, height = a × height + b.

A neap-dependent timing term would go further. Add moon age as a feature to the time calibrator, retrain with the April–August 2026 tables included, and check the result against September.

Inconsistencies

Every Jul–Sep event where the model falls outside the gate against the reference (API times corrected). There are no unmatched events: every reference tide has a model tide within 3 hours.
